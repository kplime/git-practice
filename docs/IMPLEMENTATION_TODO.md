# 소개서 기준 구현 변경 메모

작성일: 2026-10-07. 기준은 팀에서 제공한 `부캉이 아이디어 소개서.pdf`와 현재 구현 비교다.

소개·설명 문서는 소개서 기준으로 정리했다. 아래 항목은 코드·화면 변경 목록이며, 완료 범위는 작업 순서의 체크 표시와 아래 진행 기록을 따른다.

## 진행 기록 · 2026-10-08

1단계 완료: 홈 침대 상태·이탈 경과, 미복귀 설정·필터와 전용 JS/CSS를 제거했다. 설정 API에서 침대·미복귀 필드를 제외하고 수정 요청을 거절한다. 상태 API는 침대 필드를 요구·저장·응답하지 않는다. Python 정책은 침대 이탈·미복귀 신규 사건을 허용하지 않는다.

기존 DB 열·설정값·사건·처리 이력은 보존한다. 과거 미복귀는 '미복귀 · 이전 기록'으로 조회·확인·해소할 수 있고, 동일 사건의 동일 내용 재전송도 허용한다. 신규 미복귀 사건은 거절한다. 새 샘플 생성 대상은 낙상 의심·센싱 장애·기기 통신 장애이며, 기존 샘플과 사용자 처리 기록은 덮어쓰지 않는다.

2단계 완료: 활동 구간 계약·최신 활동 저장/조회·저활동 설정 API·LOW_ACTIVITY 사건 계약과 기존 DB 제약의 호환 확장을 구현했다. Python은 연속한 유효 구간만 누적하고 기준 도달 시 한 사건을 반환한다. 누락·품질 저하·재시작·출처/보정/설정 변경 시 초기화하며 중복 구간은 누적하지 않는다. 기본 저활동 감지는 꺼짐이다.

2단계 검증: Python 19개, 활동 계약·UI 31개 테스트와 임시 PostgreSQL 통합 검증이 통과했다. 실제 수집 루프와 CSI 지표 산출은 아직 없으므로 상시 실제 감지가 실행되는 상태는 아니다. 상세 계약·호출 흐름·남은 연결 부분은 [활동 데이터와 저활동 판단](./ACTIVITY_DETECTION.md)에 적었다.

3단계 완료: 홈에 실제 최신 활동 지표·측정 시각을 표시하고, 저활동 사용 여부·지속 시간·활동 기준 설정을 연결했다. 사건 목록의 저활동 필터와 상세의 시작 시각·지속 시간·당시 기준/지표를 추가했다. 신호 누락·오래된 측정·시험 데이터·조회 실패는 현재 활동값으로 표시하지 않는다. 장시간 경과나 사건 발생을 브라우저에서 추정하지 않는다.

최신 샘플은 ui-sample-v2의 24개이며, 낙상 의심·저활동·센싱 장애·기기 통신 장애와 세 처리 상태를 포함한다. 새 ID로 추가하므로 이전 샘플과 사용자 처리 이력은 그대로 남는다. 3단계에서는 JavaScript 43개 테스트와 임시 PostgreSQL 통합 검증이 통과했다. 연결 가능한 브라우저가 없어 실제 모바일 렌더링은 미검증이다. 3단계 당시 홈은 최신 측정 표시였으며, 기간별 활동 추이·이력 조회는 아래 4단계에서 추가했다.

4단계 완료: 명시적 실제 heartbeat의 활동 측정·공백을 activity_history에 저장하고, 최신 상태와 한 트랜잭션으로 갱신한다. 활동 이력 API는 최대 7일 기간·기기·커서 페이지를 지원한다. 홈은 최근 1·6·24시간 또는 날짜·시각 지정 조회, 측정 구간 그래프, 이전 기록 더 보기와 최근 기록 목록을 제공한다. 시험값·누락·오래된 측정·반복 구간을 실제 활동량으로 채우지 않는다. 기존 최신 상태를 과거 기록으로 복제하지 않는다.

4단계 검증: JavaScript 53개 테스트와 임시 PostgreSQL 통합 검증으로 시간 경계·같은 시각 페이지·중복 전송 경쟁·저장 실패 전체 롤백·화면 오류 및 늦은 응답을 확인했다. 브라우저 세션이 없어 실제 모바일 렌더링은 미검증이다. 상세 개발 계약은 [활동 이력 개발 안내](./ACTIVITY_HISTORY.md)를 참고한다.

후속 UI·조건 변경 완료: 저활동 아이콘을 다른 항목과 같은 선형 SVG로 교체하고, 민감도를 0~10 눈금 슬라이더로 표시한다. 기존 세밀한 활동 기준은 조작 전까지 유지한다. 상시·지정 시간대 설정을 DB/API/Python에 연결했으며 한국 시간·자정 넘김·종료 시 누적 초기화를 지원한다. JavaScript 57개·Python 24개·임시 PostgreSQL 통합 검증이 통과했다. 실제 CSI 수집 루프는 여전히 연결 전이다.

## 다음 수정 검토 메모 · 2026-10-09

이번 항목은 코드 검토 결과다. 아직 구현한 내용이 아니므로 완료로 표시하지 않는다.

| 순서 | 수정 후보 | 확인한 이유와 완료 기준 |
|---|---|---|
| 1 | 저활동 지속 시간과 지정 감지 시간의 조합 검증 | 감지 구간보다 긴 지속 시간을 저장할 수 있어 설정대로는 사건이 생기지 않는 조합이 있다. 상시가 아닌 경우 감지 구간 길이와 지속 시간을 검증한다. 종료 시각은 미포함이므로 길이가 같은 경계 조건도 다룬다. 서버 API와 웹에서 함께 검증하고 자정 넘김을 포함해 확인한다. |
| 2 | 사건 목록 마지막 페이지 커서 | 결과가 요청 개수와 정확히 같으면 실제로 다음 사건이 없어도 `nextCursor`를 줄 수 있다. 한 행 더 조회해 다음 항목이 있을 때만 커서를 반환한다. 정확히 20개·21개·0개 결과를 확인한다. |
| 3 | 24시간 활동 추이 집계 | 화면 표시는 최대 5,000개로 제한된다. 데이터가 촘촘하면 24시간을 모두 보여주지 못하고 가장 최근 일부만 표시한다. 실제 수집 주기를 확인한 다음 화면 구간별 집계와 측정 횟수를 표시하고 관측 공백은 계속 구분한다. 조회 구간의 앞·뒤 경계와 페이지 이동도 확인한다. |
| 4 | README·GitHub 안내 현행화 | README의 다음 구현 후보와 [GitHub 공유 안내](./GITHUB_UPLOAD.md)에 이미 구현한 저활동 기능·활동 대시보드를 구현 전으로 설명한 문구가 남아 있다. 현재 동작과 실제 CSI 연결 전 범위를 각각 일치시킨다. |
| 5 | 실제 모바일 화면 확인 | 브라우저 세션이 없어 작은 화면의 슬라이더·시각 입력·하단 메뉴 배치를 검증하지 못했다. 휴대폰 또는 사용할 수 있는 브라우저에서 직접 확인한다. |

위 1~4는 실제 기기 없이 먼저 처리할 수 있다. 5는 검증 환경이 필요하다. 검토 당시 `npm.cmd test` 57개와 Python 24개 테스트는 통과했지만, 이 결과는 위에서 발견한 새 경계 조건을 이미 검사한다는 뜻이 아니다.

### 이후 연결할 항목

- 실제 ESP32 CSI 수집·특징/활동 지표 산출·기기 환경 보정.
- 수집 세션 기준 학습/검증/시험 분리와 실제 낙상 유사 동작 모델 평가.
- 수집 루프에서 저활동 판단·시간대 설정 적용 및 재시작 처리.
- 기기 장애 감지 worker, SQLite outbox·전송 재시도, 설정 자동 동기화, 원격 Push.

이 항목들은 소개서의 최종 목표 또는 후속 후보이며, 현재 시제품에서 실제 CSI 감지나 원격 알림이 동작한다는 근거로 사용하지 않는다.

| 침대 이탈 후 미복귀 감지 설정 | 제거하고 장시간 저활동의 사용 여부·기준 시간 설정 추가 |
| 사건 목록의 미복귀 유형·필터·샘플 | 소개서 기준 목록에서 제외하고 저활동 사건 추가 |

- 미복귀와 저활동은 판단 조건이 다르므로 이름만 바꿔 재사용하지 않는다.
- 기존 DB 사건과 처리 이력은 보존하면서 전환한다. 필드·제약 변경은 기존 데이터와 호환되는 마이그레이션으로 처리한다.
- 샘플은 새 사건 계약에 맞춰 수정하며 실제 감지가 실행된 기록으로 표시하지 않는다.

## 추가할 항목

| 기능 | 필요한 작업 |
|---|---|
| 현재 활동 변화 | 실제 활동 지표·최근 변화 시각·시간에 따른 추이 표시 |
| 장시간 저활동 감지 | 유효한 관측의 활동 지표와 지속 시간 판단, 감지 설정·사건 유형·필터·상세 화면 연결 |
| 실제 CSI 수집·로컬 AI 분석 | ESP32 수신·전처리·데이터 수집·모델 학습·실시간 추론 구현 |
| 실제 낙상 유사 동작 구분 | 정상 생활 동작과 낙상 유사 동작을 구분하는 모델을 사건 생성에 연결 |
| 원격 보호자 알림 | 구독·서버 전송·수신 처리 구현. 현재 브라우저 표시 시험과 구분 |

- 센싱 중단이나 패킷 누락을 활동량 0으로 처리하지 않는다.
- 현재 Python의 RandomForest 예제는 환경 확인용이며 실제 CSI 모델이 아니다.
- 별도 '괜찮아요 / 도움이 필요해요' 버튼이나 대상자 응답 화면은 소개서에 명시되지 않았으므로 추가 대상으로 잡지 않는다.
