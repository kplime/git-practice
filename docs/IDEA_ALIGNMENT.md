기준 자료: **「부캉이 아이디어 소개서.pdf」1~2쪽**. 정리일: 2026-10-07.

## 소개서에 명시된 내용

| 항목 | 내용 |
|---|---|
| 팀·아이디어 | 부캉이 · 온가드(OnGuard) |
| 의미 | Wi-Fi 센싱 기반 비촬영 생활안전 보조 시스템 |
| 대회 분야 | AI 및 빅데이터 |
| 대상 | 독거 고령자·낙상 위험이 높은 장애인 등 생활안전 확인이 필요한 사람 |
| 수집·분석 | ESP32 기반 Wi-Fi CSI 수집과 로컬 AI 모델의 활동 변화 분석 |
| 핵심 감지 | 정상 생활 동작과 낙상 유사 동작의 구분, 장시간 저활동 |
| 확인·알림 | 사용자 확인 및 보호자 알림 |
| 대시보드 | 웹·앱에서 실시간 활동 변화와 사건·응답 이력 확인 |
| 특징 | 영상·음성 수집 없음, 신체 기기 착용 불필요 |
| 기대효과 | 착용 공백 보완, 상태 확인 지원, 돌봄 부담 감소 |

프로젝트 소개와 목표는 위 항목을 기준으로 정리했다. 상세 설명은 [프로젝트 설명](./PROJECT_PLAN.md), 실행 방법과 구현 상태는 [README](../README.md)를 참고한다.
