## 프로젝트 목표

독거 고령자나 낙상 위험이 높은 장애인 등 생활안전 확인이 필요한 사람을 위해, 카메라와 신체 착용 기기 없이 실내 활동 변화를 관측하는 안전 보조 시스템을 제안한다.

Wi-Fi CSI(Channel State Information) 데이터를 활용해 고정된 실내 환경에서 정상 생활 동작과 낙상 유사 동작의 구분 가능성을 검증한다. 낙상 의심 상황이나 장시간 저활동이 감지되면 사용자 확인 및 보호자 알림을 제공해 상태 확인을 돕는 것이 목표다.

## 해결하려는 문제

웨어러블 안전 기기는 착용하지 않은 상황에서 감시 공백이 생길 수 있고, 지속적인 착용에 불편함을 느낄 수 있다. 소개서는 수면이나 샤워 등 기기를 착용하지 못하는 상황을 이러한 공백의 예로 제시한다.

별도의 카메라나 신체 착용 기기를 요구하지 않는 Wi-Fi 센싱으로 이 공백을 보완하고, 영상 촬영이나 지속적인 착용에 부담을 느끼는 사용자에게 새로운 생활안전 서비스 선택지를 제공하고자 한다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| Wi-Fi CSI 수집 | ESP32 기반 장치로 실내 무선 채널 데이터를 수집 |
| 로컬 AI 분석 | 수집 데이터의 실내 활동 변화 패턴을 분석 |
| 낙상 유사 동작 구분 | 정상 생활 동작과 낙상 유사 동작의 구분 가능성을 검증 |
| 장시간 저활동 감지 | 활동 변화와 저활동 지속 시간을 고려해 상태 확인이 필요한 상황을 파악 |
| 사용자 확인·보호자 알림 | 낙상 의심이나 장시간 저활동 감지 시 확인과 알림 제공 |
| 웹·앱 대시보드 | 실시간 활동 변화, 사건 발생 및 응답 이력을 확인 |

## 동작 흐름

```text
ESP32 기반 장치의 Wi-Fi CSI 수집
    → 로컬 AI 모델의 활동 변화 분석
    → 낙상 유사 동작·장시간 저활동 감지
    → 사용자 확인·보호자 알림
    → 웹·앱 대시보드에서 활동·사건·응답 이력 확인
```

## 특징과 기대효과

- 카메라 영상이나 음성을 수집하지 않는 비촬영 방식.
- 신체에 기기를 착용할 필요가 없는 비착용 방식.
- ESP32 수집 장치와 로컬 AI 분석의 결합.
- 위험을 일방적으로 단정하기보다 사용자와 보호자의 상태 확인을 지원.
- 착용 공백을 보완하고 보호자의 효율적인 상태 확인과 돌봄 부담 감소를 지향.
- 무선 센서 데이터와 AI 분석을 실질적인 사회문제 해결에 적용할 가능성을 검증.
